# kontroladomu.pl

Polska platforma do organizowania przeglądów nieruchomości. Projekt powstaje od zera w
Laravel 12 i PHP 8.3.

## Status

Trwa Etap 0 — fundament aplikacji. Gotowe są lokalne środowisko PHP/MariaDB, szkielet
Laravel, testy Pest, kontrola jakości PHP oraz pierwsza polska strona startowa. Logowanie,
role, weryfikacja fachowców, wyszukiwarka i rezerwacje są jeszcze w planie.

## Wymagania lokalne

- Windows
- PHP 8.3 z rozszerzeniami wymaganymi przez Laravel
- Composer 2
- Node.js i npm
- MySQL 8 lub MariaDB 10.6+

Instrukcja uruchomienia na przygotowanym komputerze i szczegóły lokalnych ścieżek znajdują
się w [dokumentacji technicznej](docs/DOKUMENTACJA_TECHNICZNA.md).
